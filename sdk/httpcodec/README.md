# rinzu.httpcodec

Bundled bounded request-line scanning helpers for HTTP-oriented applications. This is a typed source/native package, not a complete HTTP server, router, or streaming protocol framework.

Use the exported source API for exact input bounds and failure statuses. Keep framing and application limits explicit in the caller.
