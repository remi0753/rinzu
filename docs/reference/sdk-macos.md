# rinzu.macos API

The external SDK repository maintains the generated API for `rinzu.macos` and its `document`, `document_files`, and `image_files` modules. [API reference for v0.1.0](https://github.com/remi0753/rinzu-macos/blob/v0.1.0/docs/api.md)

Register the SDK with `rinzu modules add` from your application directory. [macOS SDK setup](../libraries/macos.md)
